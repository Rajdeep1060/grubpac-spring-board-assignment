# 🚀 SprintDesk — Sprint Management Dashboard

SprintDesk is a single-page Sprint Management Application built using React 18, TypeScript, Vite, TanStack Query v5, Zustand, Tailwind CSS v3, `@dnd-kit/core`, and Recharts.

---

## 🛠️ Tech Stack & Architecture

- **Frontend Framework**: React 18 with TypeScript (Strict Mode)
- **Build Tool**: Vite
- **Server State & Polling**: TanStack Query v5
- **Client State**: Zustand with LocalStorage Persistence
- **Drag & Drop**: `@dnd-kit/core`, `@dnd-kit/sortable`
- **Charts & Data Visualisation**: Recharts
- **Styling**: Tailwind CSS v3 (Custom Design System from scratch)
- **Unit Testing**: Vitest + React Testing Library

---

## 🚀 Quick Start

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Run Vitest Unit Tests**:
   ```bash
   npm run test
   ```

4. **Run ESLint Code Quality Check**:
   ```bash
   npm run lint
   ```

5. **Build for Production**:
   ```bash
   npm run build
   ```
